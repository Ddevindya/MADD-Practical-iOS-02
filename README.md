# SE4041 – Mobile Application Design & Development

## Practical 02 – Collections & Control Flow in Swift

**Module:** SE4041 – Mobile Application Design & Development  
**Year:** Year 04 Semester 01 – 2026  
**Language:** Swift  
**Duration:** 2 Hours  

---

## Practical Overview

This practical focuses on working with multiple values using Swift collections and controlling program flow using conditions and loops.

The main collection types covered are:

- Arrays
- Sets
- Dictionaries

The practical also introduces:

- `if / else if / else`
- `switch`
- Ranges
- `for-in`
- `while`
- `repeat-while`
- `break`
- `continue`

---

## Learning Objectives

By completing this practical, I was able to:

- Create and modify arrays.
- Create and use sets.
- Perform basic set operations.
- Create and update dictionaries.
- Safely retrieve values from dictionaries.
- Use `if / else if / else` statements.
- Use `switch` statements and ranges.
- Use `for-in`, `while`, and `repeat-while` loops.
- Use `break` and `continue`.
- Combine collections and control flow in a complete Swift program.

---

## Practical Exercises

### Exercise 01 – Arrays
Worked with ordered collections, array indexing, adding and removing values, useful array properties and methods.

### Exercise 02 – Sets
Worked with unique values and set operations such as:

- Union
- Intersection
- Subtracting
- Symmetric Difference

### Exercise 03 – Dictionaries
Worked with key-value pairs, optional dictionary lookups, adding, updating, removing and searching values.

### Exercise 04 – If, Else If and Else
Used conditional statements to make decisions based on values.

### Exercise 05 – Switch and Ranges
Used `switch` statements together with closed and half-open ranges.

### Exercise 06 – Loops
Worked with:

- `for-in`
- `while`
- `repeat-while`
- `break`
- `continue`

---

## Final Challenge – Student Performance Manager

The final task combines the concepts covered in this practical.

The program:

- Stores student marks using a dictionary.
- Displays student names and marks.
- Calculates grades using `switch` and ranges.
- Stores passed students in an array.
- Stores unique grades in a set.
- Calculates the class average.
- Displays the highest and lowest marks.
- Uses control flow to process student results.
